# Privacy Policy — URL Prefix Switcher

_Last updated: September 30, 2026_

URL Prefix Switcher does not collect, store, or transmit any personal or browsing data.

## What the extension accesses

When you click the extension icon, it reads the URL of the current tab (via the `activeTab` permission) only to build the equivalent URL on `http://localhost:8080`, keeping the same path, query string and hash, and to redirect that tab to it.

## What the extension does not do

- It does not collect or store any data.
- It does not send data to any server or third party.
- It does not use analytics, tracking, or cookies.
- It does not access any tab other than the one you clicked the icon on.
